# src/components/

Design-system component zone. **Owned by Claude Design** (docs/00-design/BETK_DESIGN_BRIEF.md).

## ui/
shadcn/ui base components generated by `shadcn init`. **DO NOT MODIFY.** All tokens are CSS variables from `app/globals.css`; all components are RTL-first using Tailwind logical properties.

## shared/
Design-system components built on top of shadcn/ui. Extend, never override. Cursor wires data into these; visual changes go through Claude Design + the UI-reviewer gate (`.cursor/rules/91-review-ui.mdc`).

Planned shared components (UI Spec §4):
`ListingCard` · `StoreCard` · `PriceBlock` · `StatusBadge` · `StarRating` · `RatingSummary` · `LevelBadge` · `VerifiedBadge` · `MessageThread` · `ImageUploader` · `OrderTimeline` · `AddressForm` · `FilterSheet` · `SLABadge` · `EmptyState` · `SkeletonGrid` · `SkeletonTable` · `ErrorRetryCard` · `ConfirmDialog` · `Toaster`

Feature folders map to UI Spec areas — see `src/features/README.md`.
